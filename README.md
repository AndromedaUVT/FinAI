## About The Project

In NGO financial management, expense tracking often begins with invoices and receipts. These supporting documents come in many formats like PDFs, images, or scans from different vendors, which can make extracting, validating, and standardizing data quite manual, time-consuming, and sometimes prone to errors. That's why this project is excited to develop an Agentic AI-powered system. This system will be able to automatically extract, interpret, and normalize receipt and invoice data in various formats into a clear, organized SQL structure. It will also apply preset budget mapping rules to create standardized expense reports, making it easier to justify grants and meet donor requirements.


The objective is to build this intelligent system that handles multi-format documents effortlessly. The technology stack includes Python for the backend, Streamlit for the web interface, SQL for the database, OCR tools for document processing, and LLM-based agents for smart parsing, validation, and reasoning. Overall, this project aims to bring together document understanding, financial rules, and AI into a practical prototype that simplifies essential administrative and reporting tasks for NGOs.
